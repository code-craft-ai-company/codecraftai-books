# Security policy

This repository holds the text of the books and no running software.  If a chapter describes a security problem in one of the `codecraftai-*` or `pychestrate-*` packages, or teaches a practice that would leave a system open, please report it **privately**, not in a public issue.

Use GitHub's private vulnerability reporting: open this repository's **Security** tab, choose **Report a vulnerability**, and say which chapter and what an attacker could do.  Only the maintainers can see the report.  A problem in a package's code is best reported in that package's own repository, in the same way.

Anything that is not a security problem (an error, a question, a suggestion) belongs in a normal issue; see [CONTRIBUTING.md](CONTRIBUTING.md).

# Contributing

These books are published for reading, and the text is © Code Craft AI LLC.  The `codecraftai-*` software they describe is source-available, not open source.

## Issues are the only contribution we accept

Errata, passages that are unclear, claims that no longer match the code, and questions are welcome in the **Issues** tab.  A good issue names the volume and chapter, quotes the passage, and says what is wrong or what you expected to find.  If a chapter points at code that has moved, give the file or package you found instead.

**We do not accept pull requests or other edits to the text.**  Pull requests are limited to the maintainers, and one that arrives anyway will be closed without review.

A problem in the software itself belongs in that package's own repository, not here.  Security problems are reported privately, as described in [SECURITY.md](SECURITY.md).
